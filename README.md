# NORDRAUM — Modern E-Commerce Portfolio

A polished, responsive e-commerce experience created as a front-end portfolio project for the German job market.

## Highlights

- Responsive editorial UI for desktop, tablet and mobile
- Live products from the DummyJSON REST API with graceful offline fallback
- Category filters, search, sorting and progressive product loading
- Persistent shopping cart via `localStorage`
- Wishlist interactions, newsletter feedback and demo checkout
- Scroll reveals, micro-interactions, product parallax and reduced-motion support
- Semantic HTML, keyboard-friendly controls and accessible labels
- German-market essentials: EUR pricing, Impressum, Datenschutz and AGB links

## Tech

HTML5 · CSS3 · Vanilla JavaScript · REST API · Intersection Observer · Local Storage

## Run locally

Open `index.html`, or use any static server:

```bash
npx serve .
```

## API

Product data is loaded from [DummyJSON](https://dummyjson.com/). A curated fallback dataset keeps the interface usable if the API is unavailable.

## Portfolio note

This is a front-end demonstration. Checkout and legal pages are intentionally presented as UI concepts and do not process real payments.
